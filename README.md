\# Internship Board REST API



A RESTful API for managing internship opportunities using Node.js, Express.js, and SQLite.



\## Features



\- Create internship records

\- View all internships

\- View a single internship by ID

\- Update internship records

\- Delete internship records

\- Input validation

\- Pagination

\- SQLite persistent database

\- Consistent JSON responses

\- Seed data for testing



\## Technologies Used



\- Node.js

\- Express.js

\- SQLite

\- JavaScript

\- REST API
